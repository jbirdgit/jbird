# СМС Паркиране — синя и зелена зона

Малко уеб приложение (един файл, `index.html`) за плащане на паркиране в синя и зелена зона чрез СМС.

## Как работи

1. Въвеждате регистрационния номер (напр. `CB1234AB`) — запазва се в телефона.
2. Натискате **Синя зона** или **Зелена зона**.
3. Отваря се приложението за съобщения с готов СМС (номер + текст = рег. номер) — остава само да натиснете „Изпрати“.
4. Показва се обратно броене до изтичане на платения час, с напомняне 5 минути преди края.

По подразбиране номерата са за **София**: синя зона **1302**, зелена зона **1303**, 1 час на СМС.
За друг град ги сменете от „Настройки“.

Кирилските букви в номера (А, В, Е, К, М, Н, О, Р, С, Т, Х, У) се превръщат автоматично в латински.

## Използване

- Отворете `index.html` на телефона (или го качете на GitHub Pages) и от браузъра изберете
  „Добави към началния екран“ — ще работи като приложение.
- Уеб страница не може да изпрати СМС сама — тя само подготвя съобщението; изпращането се потвърждава от вас.
